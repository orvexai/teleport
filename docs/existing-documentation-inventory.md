## 3. Design Documents — `rfd/` (230 RFDs)

`rfd/0000-rfds.md` defines the RFD process (modeled on Oxide RFDs / IETF RFCs). Each RFD has an author, state (`draft|implemented|deprecated`), required approvers, and `What / Why / Details` sections.

Numbering is sequential; topical coverage spans the codebase. Examples:

- `0007-rbac-oss.md`, `0009-locking.md`, `0026-custom-approval-conditions.md`, `0043-kubeaccess-multiparty.md`, `0044-session-where-condition.md` — **authorization & RBAC**
- `0014-session-2FA.md`, `0015-2fa-management.md`, `0025-hsm.md`, `0040-webauthn-support.md` — **authentication & MFA**
- `0033-desktop-access.md`, `0034-desktop-access-windows.md`, `0035-desktop-access-windows-authn.md`, `0037-desktop-access-protocol.md` — **desktop access (Windows/RDP)**
- `0011-database-access.md`, `0038-database-access-aws-discovery.md`, `0046-database-access-config.md` — **database access**
- `0005-kubernetes-service.md` — **Kubernetes access**
- `0008-application-access.md` — **app access**
- `0002-streaming.md`, `0019-event-iteration-api.md`, `0042-s3-kms-encryption.md` — **audit & events**
- `0010-api.md`, `0021-cluster-routing.md`, `0039-sni-alpn-teleport-proxy-routing.md` — **proxy / API**
- `0012-teleport-versioning.md`, `0041-aws-node-join.md`, `0047-drop-vendor.md` — **operational**

> **AI guidance:** When asked about *why* something works the way it does, search `rfd/*<keyword>*.md` first. The RFD typically has more rationale than the code or git history. The index is not curated automatically — search by filename keyword.

## 7. Doc-Generator-Specific Files

`build.assets/tooling/` contains a CLI used to *generate* parts of the public docs:

- `cmd/render-helm-ref/` — generates Helm chart reference.
- `cmd/resource-ref-generator/` — generates Teleport resource reference docs from Go source tags.
- `cmd/buf-plugin-linters/` — buf lint rules for `.proto` files.
- `cmd/difftest/` — selective test runner based on git diff.
- `cmd/benchfind/` — benchmark discovery utility.

When proposing changes to user-facing reference docs, edit the *generator template* (or the source `*.go` types), not the rendered output.
