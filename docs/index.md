## Project Overview

**Teleport** is an identity-aware access platform for infrastructure (SSH, Kubernetes, databases, internal web apps, Windows desktops, Git, MCP). It mints short-lived x509 + SSH certificates instead of using long-lived secrets. The codebase is a **5-part monorepo** owned by Gravitational, Inc.

- **Type:** Monorepo (5 parts)
- **Primary language:** Go (5,893 files)
- **Secondary:** TypeScript (2,815), Rust (21 + 1 standalone), Protobuf (238), C eBPF (~10)
- **Architecture:** Service-oriented monolith binary + React UI + Electron desktop + Rust RDP library + integrations sidecars
- **License:** AGPL-3.0 (core) / Apache-2.0 (web UI + Teleterm)
- **Public docs site:** <https://goteleport.com/docs>
- **Design archive:** [`/rfd/`](../rfd/) — 230 RFDs
- **Enterprise overlay:** `/e/` (git submodule, not cloned in this workspace)

For a one-page introduction, read [`project-overview.md`](./project-overview.md).

## Getting Started

### Build

```bash
make full                       # builds all binaries + web assets
# or for faster iteration:
WEBASSETS_SKIP_BUILD=1 make build/teleport
```

See [`development-guide.md`](./development-guide.md) for the full prereqs, build variants (FIPS, BPF, FIDO2 modes), hot-reload, and code-gen workflow.

### Run

```bash
sudo mkdir -p -m0700 /var/lib/teleport
sudo chown $USER /var/lib/teleport
./build/teleport configure | sudo tee /etc/teleport.yaml > /dev/null
./build/teleport start --config=/etc/teleport.yaml
```

### Web UI

```bash
pnpm install
pnpm start-teleport             # dev server with HMR against a running cluster
pnpm storybook                  # design-system stories on :9002
```

### Teleterm (Electron)

```bash
pnpm start-term                 # electron-vite dev
pnpm package-term               # build + electron-builder package
```

### Rust RDP

```bash
make rdpclient                  # native staticlib
make build-ironrdp-wasm         # browser WASM
```

### Test

```bash
make test                       # umbrella: helm + sh + api + go + rust + operator + terraform-provider
pnpm test                       # web UI jest tests
```

## Notable Conventions

- **Single chokepoints for security.** All user certs are minted by `lib/auth/auth.go::generateCert`. All authorization decisions flow through `lib/authz/permissions.go::authorizer.Authorize`. Don't reimplement.
- **All errors wrapped with `gravitational/trace`.** Not `errors.New`. Maps to HTTP/gRPC codes.
- **Time is faked in tests.** `clockwork.NewFakeClock()`. Don't read `time.Now()` directly.
- **Resource types live in `api/types/`** and are proto-defined under `api/proto/teleport/<resource>/`.
- **New gRPC services use the v1-per-resource pattern** (`lib/auth/<resource>v1/<resource>v1/service.go`), not the legacy monolithic `AuthService`.
- **Web UI uses oxlint + oxfmt**, **not** eslint/prettier (despite some eslint deps for Storybook).
- **Web UI does REST/JSON**, not real gRPC over the network. Protobuf-ts types are used for typing only.
- **Generated code is checked in** (`gen/`, `api/gen/`, `integrations/*/gen/`, `integrations/terraform/tfschema/`).
- **`buf` is the proto generator**, with a custom lint plugin (RFD-0153 `PAGINATION_REQUIRED`).
- **There is no Spanner storage backend.** "Spanner" in code = a database engine for Database Access, not a Teleport state backend.
- **MCP servers are `KindApp` with `SubKindMCP`**, not their own kind.
- **The enterprise `/e/` submodule is not cloned here.** OSS build is self-contained.
- **AGPL-3.0 is the core license.** Web UI + Teleterm are Apache-2.0 — verify `LICENSE` before reusing.
